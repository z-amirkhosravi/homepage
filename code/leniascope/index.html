Leniascope

An implementation of Bert Chan’s Lenia, a continuous generalization of Conway’s Game of Life.

    Put it in 2D mode and press New seed (the die) several times to see how random initial seeds develop.

    Lenia is a continuous generalization of Conway’s Game of Life, where:

    • The on/off state of each pixel is replaced by a value in the real interval [0, 1].
    • The “neighbour count” of each pixel is replaced by a weighted average of an area around the pixel.
    • The discrete change in state is replaced by growth via a difference equation modelling an ODE.

    Most random initial states of enough mass evolve into the same type of almost plant-like, pseudo-periodic organism. The exception is the Orbium: it moves, has bilateral symmetry like actual living animals, and even looks vaguely like a jellyfish.

    Implementation

    Leniascope is developed in C++ with Visual Studio. An initial version was coded by hand using plain WinAPI, then subsequently expanded by Codex and re-factored to use Dear ImGUI. The web app here is a small demo of its features. The full project is on GitHub.
